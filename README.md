# Travel Website Manual Testing Project

This repository contains a complete manual testing project for a travel booking website.
https://travel.agileway.net/login
The project covers the full software testing lifecycle, including test planning, test scenarios, test cases, bug reporting, execution tracking, and Jira project management.

Contents

* Bug Reports
* Jira Board and Backlog
* Test Execution Reports
* Screenshots and Evidence

Tools Used

* Jira
* Zephyr Scale
* GitHub
* Google Chrome
* Microsoft Excel

Testing Types

* Functional Testing
* UI Testing
* Regression Testing
* Positive Testing
* Negative Testing
* Boundary Value Testing
* Exploratory Testing

Project Goal

The objective of this project is to verify that the travel website functions correctly, provides a smooth user experience, and meets the specified business requirements by identifying and documenting software defects through structured manual testing.
